# Desktop icon spec (Win98-inspired, drawn by Yves)

Eight icons, drawn in Figma, exported as PNG at 2x with no anti-aliasing.
The style is borrowed, the drawings are yours.

game.png is the exception: it is a placeholder, generated by `python3 tools/draw-game-icon.py`
in the palette below, because src/data/desktop.ts referenced it before it existed and the
desktop was showing a blank square. Replace it with a drawn one and delete that script.

## Grid
- Canvas 32×32 px. Draw with a 1px pixel grid, snap everything, no half pixels
- Keep 1px of clear margin on every side (draw inside 30×30)
- Export at 64×64 (2x) and 96×96 (3x). "Resample: Nearest neighbour" or export from a pixel plugin. Never "smooth"
- Save to `public/icons/`, referenced from `src/data/desktop.ts`

## Palette (16 colours, fixed)
Use only these. This is what makes the set feel like one system.
```
black        #000000   outline, deepest shadow
dark grey    #808080   mid shadow
light grey   #C0C0C0   base grey (PC case, bin, panel)
white        #FFFFFF   highlights
navy         #000080   screen, deep blue
blue         #0000FF   accents
teal         #008080   secondary accent
cyan         #00FFFF   screen glow
maroon       #800000   red shadow
red          #FF0000   seal, alerts
olive        #808000   yellow shadow
yellow       #FFFF00   sticky notes, highlights
green        #008000   LED, ok states
lime         #00FF00   LED highlight
purple       #800080   rare, CD sheen
magenta      #FF00FF   rare, CD sheen
```
Beige for the PC case: use light grey #C0C0C0 with white highlights, it reads beige next to the outline.

## Rules
1. 1px black outline around the whole silhouette. Inner outlines only where two materials meet
2. Light comes from top-left: white 1px highlight on top and left inner edges, dark grey on bottom and right
3. Shade with the palette, not opacity. One base colour + one highlight + one shadow per material, max
4. No gradients, no dithering except a 2px checker on large flat areas if it feels empty
5. Silhouette must read at 16px. Zoom out to check before finishing
6. Same visual weight across the set: the folder should not be twice as heavy as the envelope

## Workflow
1. Set up a 32×32 frame in Figma with a 1px layout grid, snap to pixel grid on
2. Block the silhouette in base colour, add the outline, then highlights, then shadows
3. Duplicate the frame for the hover/open state where noted
4. Export PNG @2x and @3x, set "Suffix" to @2x and @3x, drop into public/icons
5. Run `npm run dev` and view at 48px on the desktop; fix anything muddy

Reference for the style only: Windows 98 and classic Mac OS icons. Look at how they shade and outline, then close the tab and draw your own.
